# 🤖 AI Rule-Based Chatbot

A modern, responsive, and futuristic **Rule-Based Artificial Intelligence Chatbot** built using **HTML, CSS, and JavaScript**. This project demonstrates the core concepts of Artificial Intelligence through **predefined rules and if-else logic**, without relying on Machine Learning models or external AI APIs.

The chatbot can recognize predefined user inputs, generate appropriate responses, maintain chat history, support voice interaction, display analytics, and provide a premium user experience with multiple themes and animations.

---

## 📖 Description

The **AI Rule-Based Chatbot** is designed to help beginners understand how intelligent systems can be built using simple programming logic. Instead of using Machine Learning or Natural Language Processing models, this chatbot uses **rule-based decision making** with JavaScript.

The project features a modern AI-inspired interface, voice input/output, chat history management, customizable themes, analytics dashboard, and various interactive UI elements, making it an excellent portfolio project for students and developers learning Artificial Intelligence fundamentals.

## 🚀 How to Run the Project

### Method 1: Open Directly

1. Download or clone the repository.

```bash
git clone https://github.com/your-username/AI-Rule-Based-Chatbot.git
```

2. Open the project folder.

3. Double-click **index.html** or open it in your preferred web browser.

---

### Method 2: Using VS Code Live Server (Recommended)

1. Install **Visual Studio Code**.

2. Install the **Live Server** extension.

3. Open the project folder in VS Code.

4. Right-click on **index.html**.

5. Select **Open with Live Server**.

The application will automatically open in your default browser.

---

### Method 3: Using Python

If Python is installed, run the following command inside the project directory:

```bash
python -m http.server 8000
```

Then open your browser and visit:

```
http://localhost:8000
```

---

### Method 4: Using Node.js

Install the lightweight HTTP server:

```bash
npm install -g http-server
```

Run the server:

```bash
http-server
```

Open:

```
http://localhost:8080
```

## 💡 How It Works

1. The user enters a message.
2. JavaScript converts the input to lowercase.
3. The chatbot checks predefined conditions using **if-else statements**.
4. If a matching condition is found, the corresponding response is displayed.
5. If no condition matches, the chatbot returns a default response.
6. The conversation continues until the user types **bye**, **exit**, or **quit**.
